# DualSense 3D model credits

The interactive controller model used by Crown of Console is the **PS5 Controller** by **Taohid Animation**.

- Original creator: https://sketchfab.com/taohidanimation
- Original model: https://sketchfab.com/3d-models/ps5-controller-b7bb9c5102a04cb0b1966c6d02bad7d6

- Model source mirror: https://github.com/SafaElmali/dualsense-studio/blob/main/controller/dualsense.glb

The model is loaded from the credited source repository at runtime. Crown of Console adds its own Three.js lighting, presentation, button interaction and visual feedback. The model is an independent community recreation, not an official Sony asset or dimensional CAD reference.
